About

ClauseLens agreement ko clauses mein todta hai, har clause ka type pehchanta hai, key terms nikalta hai, risk (green / amber / red) batata hai, aur plain language mein samjhata hai. Sab kuch deterministic hai: explanations pehle se likhe templates hain, aur numbers seedha clause text se copy hote hain.

Limitations: classifier synthetic + CUAD/LEDGAR data pe train hua hai, isliye real Indian agreements pe accuracy gold set se napni chahiye. Scanned PDFs (OCR) supported nahi. Risk rules ek advocate se validate hone chahiye.
